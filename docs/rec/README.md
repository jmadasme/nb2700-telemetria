# rec/ — video explicativo

Este directorio contiene el video asciinema de **NB2700: ping y AT desde un router industrial** y el reproductor
que se usa en la página del proyecto.

- `nb2700-telemetria.cast`: grabación original (asciicast v2).
- `nb2700-telemetria.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 2:45. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
